🗄️ Backup & Pulihkan Database
Database aplikasi ini tersimpan lokal di perangkat/browser ini. Untuk menghindari kehilangan data (browser dihapus cache-nya, ganti perangkat, dll), unduh cadangan secara berkala dan simpan di tempat aman (flashdisk/Drive).
1. Unduh Cadangan
Cadangan berisi seluruh data: Master Penduduk, Riwayat Perubahan, Register Surat Desa, dan Pengaturan Identitas Desa — dalam satu berkas .json.
2. Pulihkan dari Cadangan
Memulihkan cadangan akan mengganti seluruh data yang ada saat ini di perangkat ini dengan isi berkas cadangan. Pastikan berkas berasal dari aplikasi ini.
